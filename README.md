# Documentos legales de Destápalas

Política de privacidad de la aplicación **Destápalas**, una colección de
solitarios para Android (`com.jrsoft.solitario`).

> **Borrador** (06/11/2026, ORDEN CG-20261106-3). Todavía no se ha publicado:
> el repositorio público `Demual/destapalas-legal` con GitHub Pages lo crea
> la sesión del proyecto cuando Javier lo apruebe, con el contenido de esta
> carpeta, como hicieron Lumidi y Siempre cabe. Antes de eso la revisa el
> agente `legal`.
>
> - Están la española (la de referencia), la inglesa y la catalana. Las otras
>   doce se traducen de la española cuando el `legal` la dé por buena, para no
>   traducir dos veces.
> - La política dice «Ajustes → Acerca de → Política de privacidad»: esa fila
>   aún no existe en la app y tiene que estar antes de publicar (con
>   `PRIVACY_URL`, como `AppConfig.privacyDocument` de Lumidi).

Cuando se publique, este repositorio existirá solo para servir esos
documentos por HTTPS con una URL pública y estable, que es requisito de Google
Play y del mensaje de consentimiento de AdMob. **No contiene el código de la
aplicación.**

La versión de referencia es la española; las demás son traducciones de la
misma versión y llevan su misma fecha. Cuando cambie la española, hay que
cambiar todas a la vez: la app enlazará cada una según su idioma.

Se publicará con GitHub Pages desde la rama `main`. El historial de commits
sirve además como registro de qué decía la política en cada momento.
